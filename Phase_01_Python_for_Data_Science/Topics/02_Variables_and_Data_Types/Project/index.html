Phase 01: Python for Data Science Project ০২: Visual Walkthrough

ভেরিয়েবল ও ডেটা টাইপস: মার্কেট টিক ডেটা মডেলিং

ট্রেডিং প্রেক্ষাপট: লাইভ এক্সচেঞ্জ টিক ফিড থেকে একটি অ্যাসেটের সিম্বল, ওএইচএলসি প্রাইস, ভলিউম ও বুলিশ স্ট্যাটাস ভেরিয়েবলে সংরক্ষণ এবং ডেটা টাইপ রূপান্তর।

০১ ধাপ ১: মার্কেট টিক ভেরিয়েবল ডিফাইন ও টাইপ চেক

step_01.py 
symbol = "BTC/USDT"
entry_price = 67450.50
trade_volume = 12
is_bullish = True

print("Asset:", symbol, "| Type:", type(symbol).__name__)
print("Entry Price: $", entry_price, "| Type:", type(entry_price).__name__)
print("Volume:", trade_volume, "| Type:", type(trade_volume).__name__)
print("Bullish Status:", is_bullish, "| Type:", type(is_bullish).__name__)
Terminal Output
Asset: BTC/USDT | Type: str
Entry Price: $ 67450.5 | Type: float
Volume: 12 | Type: int
Bullish Status: True | Type: bool
লাইন-বাই-লাইন বিশ্লেষণ: আমরা পাইথনের চারটি মৌলিক ডেটা টাইপ দিয়ে একটি ট্রেডিং টিক রেকর্ড তৈরি করেছি। type() ফাংশন দিয়ে যাচাই করা হয়েছে প্রতিটি ভেরিয়েবলের আসল ক্লাস।

০২ ধাপ ২: স্ট্রিং থেকে নিউমেরিক রূপান্তর (Type Casting)

step_02.py 
raw_api_price = "67450.50"
raw_api_volume = "15"

parsed_price = float(raw_api_price)
parsed_volume = int(raw_api_volume)
notional_value = parsed_price * parsed_volume

print("Parsed Price: $", parsed_price)
print("Parsed Volume:", parsed_volume, "contracts")
print("Total Notional Value: $", round(notional_value, 2))
Terminal Output
Parsed Price: $ 67450.5
Parsed Volume: 15 contracts
Total Notional Value: $ 1011757.5
লাইন-বাই-লাইন বিশ্লেষণ: ব্রোকার API থেকে প্রাপ্ত প্রাইস ও ভলিউম স্ট্রিং ফরম্যাটে আসে। float() ও int() কাস্টিং করে সঠিক গাণিতিক মান বের করা হয়েছে।

০৩ ধাপ ৩: ট্রেড টিকেট সামারি ফরম্যাটিং (f-strings)

step_03.py

লাইন-বাই-লাইন বিশ্লেষণ: f-strings ব্যবহার করে সংখ্যার কমা ফরম্যাটিং এবং ডেসিমাল নিয়ন্ত্রণ করে পেশাদার ট্রেড কনফার্মেশন টিকেট তৈরি করা হয়েছে।

০৪ সম্পূর্ণ কার্যকর কোড (Full Script)

নিচের কোডটি এক ট্যাপে কপি করে অন্য যেকোনো জায়গায় টেস্ট বা স্টাডি করতে পারেন:

complete_solution.py 
# Variables & Data Types in Market Tick Data

# 1. ধাপ ১: মার্কেট টিক ভেরিয়েবল ডিফাইন ও টাইপ চেক
symbol = "BTC/USDT"
entry_price = 67450.50
trade_volume = 12
is_bullish = True

print("Asset:", symbol, "| Type:", type(symbol).__name__)
print("Entry Price: $", entry_price, "| Type:", type(entry_price).__name__)
print("Volume:", trade_volume, "| Type:", type(trade_volume).__name__)
print("Bullish Status:", is_bullish, "| Type:", type(is_bullish).__name__)

# 2. ধাপ ২: স্ট্রিং থেকে নিউমেরিক রূপান্তর (Type Casting)
raw_api_price = "67450.50"
raw_api_volume = "15"

parsed_price = float(raw_api_price)
parsed_volume = int(raw_api_volume)
notional_value = parsed_price * parsed_volume

print("Parsed Price: $", parsed_price)
print("Parsed Volume:", parsed_volume, "contracts")
print("Total Notional Value: $", round(notional_value, 2))

# 3. ধাপ ৩: ট্রেড টিকেট সামারি ফরম্যাটিং (f-strings)
portfolio_id = "QUANT-ALPHA-01"
leverage = 5
margin_required = notional_value / leverage

trade_ticket = f"""[TRADE TICKET]
Account  : {portfolio_id}
Asset    : {symbol}
Position : {parsed_volume} units @ ${parsed_price:,.2f}
Notional : ${notional_value:,.2f}
Margin   : ${margin_required:,.2f} ({leverage}x Leverage)"""

print(trade_ticket)
