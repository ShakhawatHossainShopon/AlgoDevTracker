Phase 01: Python for Data Science Topic ০২: Variables & Data Types in Market Tick Data

ভেরিয়েবল ও ডেটা টাইপস: মার্কেট টিক ডেটা মডেলিং

লাইভ এক্সচেঞ্জ টিক ফিড থেকে একটি অ্যাসেটের সিম্বল, ওএইচএলসি প্রাইস, ভলিউম ও বুলিশ স্ট্যাটাস ভেরিয়েবলে সংরক্ষণ এবং ডেটা টাইপ রূপান্তর।

০১ থিওরি ও মূল কনসেপ্ট

ট্রেডিং অ্যালগরিদমে ডেটা টাইপ কেন অপরিহার্য?

প্রতিটি কোয়ান্ট ট্রেডিং সিস্টেমে মার্কেট থেকে আসা রিয়েল-টাইম টিক ডেটা পার্স করতে হয়। পাইথনের প্রধান ৪টি ডেটা টাইপ এখানে ব্যবহার হয়:

  • str (String): অ্যাসেট বা কারেন্সি পেয়ারের নাম (যেমন: "BTC/USDT", "EUR/USD")।
  • float (Floating Point): ক্যান্ডেলের দাম এবং সূচক মান (যেমন: 67450.50, 1.0845)।
  • int (Integer): ট্রেডিং ভলিউম বা লট সংখ্যা (যেমন: 15, 100)।
  • bool (Boolean): সিগন্যাল ট্রিগার বা বুলিশ/বেয়ারিশ স্ট্যাটাস (যেমন: True, False)।

ব্রোকার API থেকে অনেক সময় দাম স্ট্রিং আকারে আসে। তাই float() এবং int() দিয়ে টাইপ কাস্টিং করে সঠিক গাণিতিক মান বের করতে হয়।

০২ বাস্তব ট্রেডিং কোড উদাহরণ

trading_example.py 
symbol = "BTC/USDT"
entry_price = 67450.50
trade_volume = 12
is_bullish = True

print("Asset:", symbol, "| Type:", type(symbol).__name__)
print("Entry Price: $", entry_price, "| Type:", type(entry_price).__name__)
print("Volume:", trade_volume, "| Type:", type(trade_volume).__name__)
print("Bullish Status:", is_bullish, "| Type:", type(is_bullish).__name__)
Terminal Output
Asset: BTC/USDT | Type: str
Entry Price: $ 67450.5 | Type: float
Volume: 12 | Type: int
Bullish Status: True | Type: bool
ব্যাখ্যা: আমরা পাইথনের চারটি মৌলিক ডেটা টাইপ দিয়ে একটি ট্রেডিং টিক রেকর্ড তৈরি করেছি। type() ফাংশন দিয়ে যাচাই করা হয়েছে প্রতিটি ভেরিয়েবলের আসল ক্লাস।

০৩ মোবাইল রিডিং টেকঅ্যাওয়ে (Key Takeaways)

  • রিয়েল-ওয়ার্ল্ড অ্যাপ্লিকেশন: লাইভ এক্সচেঞ্জ টিক ফিড থেকে একটি অ্যাসেটের সিম্বল, ওএইচএলসি প্রাইস, ভলিউম ও বুলিশ স্ট্যাটাস ভেরিয়েবলে সংরক্ষণ এবং ডেটা টাইপ রূপান্তর।
  • দক্ষতা অর্জন: অ্যালগরিদমিক ট্রেডিং সিস্টেমে ডেটার সঠিক আর্কিটেকচার ও গণনা নিশ্চিত করা।
  • পরবর্তী পদক্ষেপ: নিচের বাটনে ট্যাপ করে প্রজেক্ট ল্যাব ড্যাশবোর্ডে গিয়ে ধাপে ধাপে সম্পূর্ণ কোড ওয়াকথ্রু দেখে নিন।
