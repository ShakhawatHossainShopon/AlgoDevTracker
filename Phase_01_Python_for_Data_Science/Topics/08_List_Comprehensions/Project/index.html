Phase 01: Python for Data Science Project ০৮: Visual Walkthrough

লিস্ট কম্প্রিহেনশন: ভেক্টরাইজড রিটার্ন পাইপলাইন

ট্রেডিং প্রেক্ষাপট: ক্যান্ডেলস্টিক তালিকা থেকে এক লাইনে বুলিশ ক্যান্ডেল ফিল্টার করা এবং রিটার্ন সিরিজ তৈরি।

০১ ধাপ ১: এক লাইনে রিটার্ন ক্যালকুলেশন

step_01.py 
prices = [100.0, 102.5, 101.0, 104.0, 106.5]

returns = [round((prices[i] - prices[i-1]) / prices[i-1] * 100, 2) for i in range(1, len(prices))]
print("Calculated Returns (%):", returns)
Terminal Output
Calculated Returns (%): [2.5, -1.46, 2.97, 2.4]
লাইন-বাই-লাইন বিশ্লেষণ: লিস্ট কম্প্রিহেনশনের মাধ্যমে ক্যান্ডেলগুলোর শতকরা লাভ/লস এক লাইনে রূপান্তর।

০২ ধাপ ২: শর্তযুক্ত ফিল্টারিং (Conditional Comprehension)

step_02.py 
# শুধুমাত্র পজিটিভ রিটার্নগুলো ফিল্টার করা
winning_trades = [r for r in returns if r > 0]
win_rate = (len(winning_trades) / len(returns)) * 100

print("Winning Trades (%):", winning_trades)
print("Win Rate:", win_rate, "%")
Terminal Output
Winning Trades (%): [2.5, 2.97, 2.4]
Win Rate: 75.0 %
লাইন-বাই-লাইন বিশ্লেষণ: if ফিল্টার যুক্ত করে উইনিং ট্রেডগুলোর তালিকা ও উইন রেট তৈরি করা।

০৩ ধাপ ৩: ডিকশনারি কম্প্রিহেনশন দিয়ে টিকার ম্যাপিং

step_03.py 
symbols = ["BTC", "ETH", "SOL"]
prices_usd = [67400, 3500, 175]

market_map = {sym: pr for sym, pr in zip(symbols, prices_usd)}
print("Market Price Map:", market_map)
Terminal Output
Market Price Map: {'BTC': 67400, 'ETH': 3500, 'SOL': 175}
লাইন-বাই-লাইন বিশ্লেষণ: zip() ও ডিকশনারি কম্প্রিহেনশন দিয়ে একাধিক লিস্টকে এক পলকে ডিকশনারিতে রূপান্তর।

০৪ সম্পূর্ণ কার্যকর কোড (Full Script)

নিচের কোডটি এক ট্যাপে কপি করে অন্য যেকোনো জায়গায় টেস্ট বা স্টাডি করতে পারেন:

complete_solution.py 
# List Comprehensions in Return Calculations

# 1. ধাপ ১: এক লাইনে রিটার্ন ক্যালকুলেশন
prices = [100.0, 102.5, 101.0, 104.0, 106.5]

returns = [round((prices[i] - prices[i-1]) / prices[i-1] * 100, 2) for i in range(1, len(prices))]
print("Calculated Returns (%):", returns)

# 2. ধাপ ২: শর্তযুক্ত ফিল্টারিং (Conditional Comprehension)
# শুধুমাত্র পজিটিভ রিটার্নগুলো ফিল্টার করা
winning_trades = [r for r in returns if r > 0]
win_rate = (len(winning_trades) / len(returns)) * 100

print("Winning Trades (%):", winning_trades)
print("Win Rate:", win_rate, "%")

# 3. ধাপ ৩: ডিকশনারি কম্প্রিহেনশন দিয়ে টিকার ম্যাপিং
symbols = ["BTC", "ETH", "SOL"]
prices_usd = [67400, 3500, 175]

market_map = {sym: pr for sym, pr in zip(symbols, prices_usd)}
print("Market Price Map:", market_map)
