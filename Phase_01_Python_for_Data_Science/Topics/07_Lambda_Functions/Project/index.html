Phase 01: Python for Data Science Project ০৭: Visual Walkthrough

ল্যাম্বডা ফাংশনস: ফাস্ট অর্ডারবুক সর্টিং ও ট্রান্সফরমেশন

ট্রেডিং প্রেক্ষাপট: লাইভ অর্ডারবুকের গভীরতার অর্ডারগুলোকে ল্যাম্বডা দিয়ে দ্রুত সর্ট করা এবং ম্যাপ ও ফিল্টার প্রয়োগ।

০১ ধাপ ১: ল্যাম্বডা দিয়ে অর্ডারবুক সর্টিং

step_01.py 
orders = [
    {"id": 1, "price": 67420.0, "qty": 1.5},
    {"id": 2, "price": 67400.0, "qty": 4.2},
    {"id": 3, "price": 67450.0, "qty": 0.8}
]

# সর্বোচ্চ দামের অর্ডার সবার আগে রাখা (বিড সর্টিং)
sorted_bids = sorted(orders, key=lambda x: x["price"], reverse=True)
print("Top Bid Order ID:", sorted_bids[0]["id"], "at Price: $", sorted_bids[0]["price"])
Terminal Output
Top Bid Order ID: 3 at Price: $ 67450.0
লাইন-বাই-লাইন বিশ্লেষণ: lambda x: x['price'] দিয়ে ডিকশনারি তালিকার মধ্য থেকে দাম অনুযায়ী অর্ডার সাজানো হয়েছে।

০২ ধাপ ২: map() এর সাথে ল্যাম্বডা রিটার্ন রূপান্তর

step_02.py 
close_prices = [100.0, 102.0, 105.0, 103.0]
entry = 100.0

pct_returns = list(map(lambda p: round(((p - entry) / entry) * 100, 2), close_prices))
print("Percentage Returns from Entry:", pct_returns)
Terminal Output
Percentage Returns from Entry: [0.0, 2.0, 5.0, 3.0]
লাইন-বাই-লাইন বিশ্লেষণ: map() এবং ল্যাম্বডা দিয়ে এক লাইনে সম্পূর্ণ প্রাইস লিস্টকে রিটার্নে কনভার্ট করা হয়েছে।

০৩ ধাপ ৩: filter() এর সাথে ল্যাম্বডা ভলিউম স্পাইক ফিল্টার

step_03.py 
ticks = [
    {"vol": 12, "symbol": "BTC"},
    {"vol": 85, "symbol": "ETH"},
    {"vol": 120, "symbol": "SOL"},
    {"vol": 45, "symbol": "AVAX"}
]

high_volume = list(filter(lambda t: t["vol"] >= 80, ticks))
print("High Volume Spikes Detected:", [t["symbol"] for t in high_volume])
Terminal Output
High Volume Spikes Detected: ['ETH', 'SOL']
লাইন-বাই-লাইন বিশ্লেষণ: filter() দিয়ে ৮০ বা তার বেশি ভলিউমের অ্যাসেটগুলো নিমেষেই ফিল্টার করা হয়েছে।

০৪ সম্পূর্ণ কার্যকর কোড (Full Script)

নিচের কোডটি এক ট্যাপে কপি করে অন্য যেকোনো জায়গায় টেস্ট বা স্টাডি করতে পারেন:

complete_solution.py 
# Lambda Functions for Rapid Order Book Sorting

# 1. ধাপ ১: ল্যাম্বডা দিয়ে অর্ডারবুক সর্টিং
orders = [
    {"id": 1, "price": 67420.0, "qty": 1.5},
    {"id": 2, "price": 67400.0, "qty": 4.2},
    {"id": 3, "price": 67450.0, "qty": 0.8}
]

# সর্বোচ্চ দামের অর্ডার সবার আগে রাখা (বিড সর্টিং)
sorted_bids = sorted(orders, key=lambda x: x["price"], reverse=True)
print("Top Bid Order ID:", sorted_bids[0]["id"], "at Price: $", sorted_bids[0]["price"])

# 2. ধাপ ২: map() এর সাথে ল্যাম্বডা রিটার্ন রূপান্তর
close_prices = [100.0, 102.0, 105.0, 103.0]
entry = 100.0

pct_returns = list(map(lambda p: round(((p - entry) / entry) * 100, 2), close_prices))
print("Percentage Returns from Entry:", pct_returns)

# 3. ধাপ ৩: filter() এর সাথে ল্যাম্বডা ভলিউম স্পাইক ফিল্টার
ticks = [
    {"vol": 12, "symbol": "BTC"},
    {"vol": 85, "symbol": "ETH"},
    {"vol": 120, "symbol": "SOL"},
    {"vol": 45, "symbol": "AVAX"}
]

high_volume = list(filter(lambda t: t["vol"] >= 80, ticks))
print("High Volume Spikes Detected:", [t["symbol"] for t in high_volume])

--- Step 2 Output ---
