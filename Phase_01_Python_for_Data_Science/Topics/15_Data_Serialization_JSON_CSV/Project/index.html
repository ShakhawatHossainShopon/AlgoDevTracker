ডেটা সিরিয়ালাইজেশন (JSON ও CSV): মার্কেট ফিড এনকোডিং ও ডিকম্প্রেশন

ট্রেডিং প্রেক্ষাপট: মার্কেট টিক অবজেক্টকে JSON স্ট্রিংয়ে সিরিয়ালাইজ করা এবং ক্যান্ডেলস্টিক ডেটা CSV ফরম্যাটে এক্সপোর্ট করা।

০১ ধাপ ১: JSON সিরিয়ালাইজেশন ও ডিসিরিয়ালাইজেশন

step_01.py 
import json

tick_data = {
    "symbol": "BTC/USDT",
    "bids": [[67400.0, 1.2], [67390.0, 3.5]],
    "asks": [[67410.0, 0.8], [67420.0, 2.0]],
    "is_active": True
}

# Python Dict to JSON String
json_payload = json.dumps(tick_data)
# JSON String to Python Dict
parsed_back = json.loads(json_payload)

print("JSON String Payload:", json_payload)
print("Parsed Back Best Bid Price:", parsed_back["bids"][0][0])
Terminal Output
JSON String Payload: {"symbol": "BTC/USDT", "bids": [[67400.0, 1.2], [67390.0, 3.5]], "asks": [[67410.0, 0.8], [67420.0, 2.0]], "is_active": true}
Parsed Back Best Bid Price: 67400.0
লাইন-বাই-লাইন বিশ্লেষণ: json.dumps() এবং json.loads() দিয়ে মেমোরি অবজেক্ট এবং নেটওয়ার্ক স্ট্রিং এর মধ্যে নিখুঁত রূপান্তর।

০২ ধাপ ২: CSV ফরম্যাটে ক্যান্ডেল ডেটা এক্সপোর্ট

step_02.py 
import csv
import io

candles = [
    ["timestamp", "open", "high", "low", "close", "volume"],
    ["2026-11-19T20:00Z", 67100, 67300, 67050, 67250, 420.5],
    ["2026-11-19T21:00Z", 67250, 67500, 67200, 67480, 580.2]
]

output = io.StringIO()
writer = csv.writer(output)
writer.writerows(candles)

print("Serialized CSV Data:")
print(output.getvalue().strip())
Terminal Output
Serialized CSV Data:
timestamp,open,high,low,close,volume
2026-11-19T20:00Z,67100,67300,67050,67250,420.5
2026-11-19T21:00Z,67250,67500,67200,67480,580.2
লাইন-বাই-লাইন বিশ্লেষণ: csv.writer ব্যবহার করে ক্যান্ডেলস্টিক ডেটাকে স্ট্যান্ডার্ড কমা-সেপারেটেড ফরম্যাটে এক্সপোর্ট করা।
