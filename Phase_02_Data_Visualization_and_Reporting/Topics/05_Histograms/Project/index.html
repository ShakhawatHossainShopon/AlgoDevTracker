টপিক ০৫: হিস্টোগ্রাম ও রিটার্ন ডিস্ট্রিবিউশন অ্যানালাইসিস — প্র্যাকটিক্যাল ল্যাব

ঐতিহাসিক ডেইলি রিটার্নসের হিস্টোগ্রাম প্লট করে নরমাল বেল কার্ভের সাথে তুলনা এবং আউটলায়ার টেল সনাক্তকরণ।

প্রজেক্ট অবজেক্টিভ: নিচের কোড ব্লকগুলো ধাপে ধাপে পর্যবেক্ষণ করে অ্যালগরিদমটি কীভাবে কাজ করে তা আয়ত্ত করুন। প্রতিটি কোডের জন্য ওয়ান-ট্যাপ কপি বাটন রয়েছে।

০১ রিটার্ন হিস্টোগ্রাম প্লটিং

step_01.py 
import matplotlib.pyplot as plt
import numpy as np

# ১০০০ দিনের র্যান্ডম রিটার্ন (Fat-tailed Student-t ডিস্ট্রিবিউশন)
np.random.seed(42)
returns = np.random.standard_t(df=5, size=1000) * 0.015

fig, ax = plt.subplots(figsize=(8, 4))
counts, bins, patches = ax.hist(returns * 100, bins=40, density=True, color="#3b82f6", alpha=0.7, edgecolor="white")

ax.set_title("Asset Daily Returns Frequency Distribution", fontweight="bold")
ax.set_xlabel("Daily Return (%)")
ax.set_ylabel("Probability Density")
ax.grid(True, linestyle="--", alpha=0.3)

print("Histogram Bins Count:", len(bins) - 1)
print("Min Return (%):", round(returns.min() * 100, 2))
print("Max Return (%):", round(returns.max() * 100, 2))
Terminal Output
Histogram Bins Count: 40
Min Return (%): -6.74
Max Return (%): 7.39
লাইন-বাই-লাইন বিশ্লেষণ: density=True দিয়ে প্রোবাবিলিটি ডেনসিটিতে হিস্টোগ্রাম প্লট করা হয়েছে যাতে তাত্ত্বিক কার্ভের সাথে মেলানো যায়।

০২ নরমাল ডিস্ট্রিবিউশন কার্ভ ওভারলে

step_02.py 
from scipy.stats import norm

# রিটার্নের গড় ও স্ট্যান্ডার্ড ডেভিয়েশন
mu = (returns * 100).mean()
sigma = (returns * 100).std()

x_vals = np.linspace(bins[0], bins[-1], 200)
pdf = norm.pdf(x_vals, mu, sigma)

ax.plot(x_vals, pdf, color="#ef4444", linewidth=2, label="Normal Bell Curve Overlay")
ax.legend()

print("Normal Bell Curve Plotted.")
print(f"Fitted Normal: Mean={mu:.3f}%, Sigma={sigma:.3f}%")
Terminal Output
Normal Bell Curve Plotted.
Fitted Normal: Mean=-0.007%, Sigma=1.921%
লাইন-বাই-লাইন বিশ্লেষণ: scipy.stats.norm.pdf দিয়ে তাত্ত্বিক নরমাল কার্ভ হিস্টোগ্রামের ওপর বসিয়ে ফ্যাট টেইলস যাচাই করা হয়েছে।

০৩ রিস্ক থ্রেশহোল্ড (VaR 95%) ভার্টিক্যাল লাইন

var_line = np.percentile(returns * 100, 5)
