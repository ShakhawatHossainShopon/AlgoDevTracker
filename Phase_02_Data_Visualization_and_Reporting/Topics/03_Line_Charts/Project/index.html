টপিক ০৩: লাইন চার্ট ও মুভিং অ্যাভারেজ গোল্ডেন ক্রস — প্র্যাকটিক্যাল ল্যাব

হিস্টোরিক্যাল প্রাইসের সাথে ৫০ ও ২০০ পিরিয়ডের সিম্পল মুভিং অ্যাভারেজ (SMA) ক্রসওভার ভিজ্যুয়ালাইজেশন ও সিগন্যাল মার্কিং।

প্রজেক্ট অবজেক্টিভ: নিচের কোড ব্লকগুলো ধাপে ধাপে পর্যবেক্ষণ করে অ্যালগরিদমটি কীভাবে কাজ করে তা আয়ত্ত করুন। প্রতিটি কোডের জন্য ওয়ান-ট্যাপ কপি বাটন রয়েছে।

০১ মুভিং অ্যাভারেজ লাইন প্লটিং

step_01.py 
import matplotlib.pyplot as plt
import numpy as np

periods = np.arange(1, 11)
price = np.array([100, 102, 105, 107, 106, 110, 114, 118, 122, 125])
sma_fast = np.array([np.nan, np.nan, 102.3, 104.7, 106.0, 107.7, 110.0, 114.0, 118.0, 121.7])
sma_slow = np.array([np.nan, np.nan, np.nan, np.nan, 104.0, 106.0, 108.4, 111.0, 114.4, 117.8])

fig, ax = plt.subplots(figsize=(8, 4))
ax.plot(periods, price, label="Close Price", color="#94a3b8", alpha=0.6)
ax.plot(periods, sma_fast, label="SMA 3 (Fast)", color="#2563eb", linewidth=2)
ax.plot(periods, sma_slow, label="SMA 5 (Slow)", color="#ea580c", linewidth=2)

ax.set_title("SMA Crossover Strategy Visualization")
ax.legend()
ax.grid(True, linestyle=":", alpha=0.6)

print("SMA Fast and Slow Lines Plotted.")
Terminal Output
SMA Fast and Slow Lines Plotted.
লাইন-বাই-লাইন বিশ্লেষণ: বিভিন্ন উইন্ডোর মুভিং অ্যাভারেজকে ভিন্ন রঙের লাইনে প্লট করে ট্রেন্ড আইডেন্টিফাই করা হয়েছে।

# 1. মুভিং অ্যাভারেজ লাইন প্লটিং
import matplotlib.pyplot as plt
import numpy as np

periods = np.arange(1, 11)
price = np.array([100, 102, 105, 107, 106, 110, 114, 118, 122, 125])
sma_fast = np.array([np.nan, np.nan, 102.3, 104.7, 106.0, 107.7, 110.0, 114.0, 118.0, 121.7])
sma_slow = np.array([np.nan, np.nan, np.nan, np.nan, 104.0, 106.0, 108.4, 111.0, 114.4, 117.8])

fig, ax = plt.subplots(figsize=(8, 4))
ax.plot(periods, price, label="Close Price", color="#94a3b8", alpha=0.6)
ax.plot(periods, sma_fast, label="SMA 3 (Fast)", color="#2563eb", linewidth=2)
ax.plot(periods, sma_slow, label="SMA 5 (Slow)", color="#ea580c", linewidth=2)

ax.set_title("SMA Crossover Strategy Visualization")
ax.legend()

print("SMA Fast and Slow Lines Plotted.")
