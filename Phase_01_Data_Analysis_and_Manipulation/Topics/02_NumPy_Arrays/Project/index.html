টপিক ০২: NumPy অ্যারে তৈরি ও স্ট্রাইডস মেকানিজম — প্র্যাকটিক্যাল ল্যাব

অ্যালগো ট্রেডিং সার্ভারে অর্ডারবুক ডেপ্থ (Bid/Ask 10 লেভেল) এবং ওএইচএলসিভি (OHLCV) ম্যাট্রিক্স জিরো-ওভারহেডে ইনিশিয়ালাইজ ও রি-শেপিং করা।

প্রজেক্ট অবজেক্টিভ: নিচের কোড ব্লকগুলো ধাপে ধাপে পর্যবেক্ষণ করে অ্যালগরিদমটি কীভাবে কাজ করে তা আয়ত্ত করুন। প্রতিটি কোডের জন্য ওয়ান-ট্যাপ কপি বাটন রয়েছে।

০১ মাল্টি-লেভেল অর্ডারবুক ম্যাট্রিক্স ইনিশিয়ালাইজ

step_01.py 
import numpy as np

# ১০ লেভেলের Bid-Ask অর্ডারবুক ম্যাট্রিক্স: [Level, [Price, Volume]]
orderbook = np.zeros((10, 2), dtype=np.float64)

# লেভেল ১ ও ২ এ প্রাইস ও ভলিউম সেট করা
orderbook[0] = [67500.0, 4.25]
orderbook[1] = [67490.0, 12.80]

print("Orderbook Shape:", orderbook.shape)
print("Orderbook Memory Bytes:", orderbook.nbytes)
print("Top 2 Levels:
", orderbook[:2])
Terminal Output
Orderbook Shape: (10, 2)
Orderbook Memory Bytes: 160
Top 2 Levels:
 [[67500.       4.25]
 [67490.      12.8 ]]
লাইন-বাই-লাইন বিশ্লেষণ: np.zeros দিয়ে ফিক্সড সাইজের অর্ডারবুক বাফার বানিয়ে সরাসরি ইনডেক্সিংয়ের মাধ্যমে ডেটা আপডেট করা হয়েছে।

০২ OHLCV 2D বার ম্যাট্রিক্স ও রেঞ্জ তৈরি

step_02.py 
# সিন্থেটিক মিনিট বারের টাইম ও প্রাইস ম্যাট্রিক্স
timestamps = np.arange(1700000000, 1700000300, 60)
prices = np.linspace(67100, 67450, len(timestamps))

market_data = np.column_stack((timestamps, prices))
print("Market Data Shape:", market_data.shape)
print("First 3 Rows:
", market_data[:3])
Terminal Output
Market Data Shape: (5, 2)
First 3 Rows:
 [[1.7000e+09 6.7100e+04]
 [1.7000e+09 6.7187e+04]
 [1.7000e+09 6.7275e+04]]
লাইন-বাই-লাইন বিশ্লেষণ: np.arange ও np.linspace ব্যবহার করে টাইমস্ট্যাম্প এবং লিনিয়ার প্রাইস তৈরি করে np.column_stack দিয়ে 2D ম্যাট্রিক্স সাজানো হয়েছে।

০৩ অ্যারে স্ট্রাইডস ও ফ্ল্যাটেনিং

matrix = np.array([[10, 20], [30, 40], [50, 60]], dtype=np.int32)

print("Matrix Shape:", matrix.shape)
print("Strides (Bytes per step):", matrix.strides)
print("Flattened View:", matrix.ravel())
Terminal Output
Matrix Shape: (3, 2)
Strides (Bytes per step): (8, 4)
Flattened View: [10 20 30 40 50 60]
লাইন-বাই-লাইন বিশ্লেষণ: প্রতিটি সারি অতিক্রম করতে ৮ বাইট এবং প্রতিটি কলামে যেতে ৪ বাইট স্ট্রাইড ব্যবহার হয়।
