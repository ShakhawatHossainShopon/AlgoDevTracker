Phase 01: Data Analysis & Manipulation Topic 04: Broadcasting in Financial Matrices

টপিক ০৪: ব্রডকাস্টিং ও মাল্টি-অ্যাসেট ফি ক্যালকুলেশন

ভিন্ন শেপের ম্যাট্রিক্সে লুপ না চালিয়ে সম্পূর্ণ পোর্টফোলিও প্রাইস ম্যাট্রিক্সের ওপর ব্রোকারেজ ফি এবং বিড-আস্ক স্প্রেড একবারে অ্যাডজাস্ট করা।

০১ থিওরি ও মূল কনসেপ্ট

Broadcasting হলো NumPy-এর এমন একটি বৈশিষ্ট্য যা ভিন্ন আকারের (Shape) অ্যারের মধ্যে সরাসরি গাণিতিক অপারেশন করতে সাহায্য করে। ছোট অ্যারেটি স্বয়ংক্রিয়ভাবে বড় অ্যারের আকারের সাথে ভার্চুয়ালি প্রসারিত হয় কোনো অতিরিক্ত মেমোরি খরচ না করে।

  • রুল ১: দুটি অ্যারের ডাইমেনশন সমান না হলে বাম পাশে ১ যোগ করে ডাইমেনশন মেলানো হয়।
  • রুল ২: যেকোনো ডাইমেনশনে সাইজ ১ হলে তা অপর অ্যারের ডাইমেনশনের সমান হয়ে যায়।

০২ বাস্তব ট্রেডিং কোড উদাহরণ

trading_example.py 
import numpy as np

# ৪টি অ্যাসেটের ৩ দিনের ক্লোজিং প্রাইস (3 x 4)
# Assets: [BTC, ETH, SOL, BNB]
prices = np.array([
    [67000.0, 3500.0, 180.0, 590.0],
    [67200.0, 3540.0, 185.0, 595.0],
    [67100.0, 3520.0, 182.0, 592.0]
])

# প্রতিটি অ্যাসেটের ফিক্সড স্প্রেড (1D array of 4 elements)
spreads = np.array([2.5, 0.5, 0.1, 0.2])

# ব্রডকাস্টিংয়ের মাধ্যমে আস্ক প্রাইস ম্যাট্রিক্স
ask_prices = prices + spreads
print("Original Prices (Day 1):", prices[0])
print("Ask Prices with Spread (Day 1):", ask_prices[0])
Terminal Output
Original Prices (Day 1): [67000.  3500.   180.   590.]
Ask Prices with Spread (Day 1): [67002.5  3500.5   180.1   590.2]
ব্যাখ্যা: (3, 4) ম্যাট্রিক্স এবং (4,) ভেক্টরের মধ্যে ব্রডকাস্টিং হয়ে প্রতিটি অ্যাসেটের নিজস্ব স্প্রেড নির্ভুলভাবে যোগ হয়েছে।

০৩ মোবাইল রিডিং টেকঅ্যাওয়ে (Key Takeaways)

  • রিয়েল-ওয়ার্ল্ড অ্যাপ্লিকেশন: ভিন্ন শেপের ম্যাট্রিক্সে লুপ না চালিয়ে সম্পূর্ণ পোর্টফোলিও প্রাইস ম্যাট্রিক্সের ওপর ব্রোকারেজ ফি এবং বিড-আস্ক স্প্রেড একবারে অ্যাডজাস্ট করা।
  • দক্ষতা অর্জন: অ্যালগরিদমিক ট্রেডিং সিস্টেমে ডেটার সঠিক আর্কিটেকচার ও গণনা নিশ্চিত করা।
  • পরবর্তী পদক্ষেপ: নিচের বাটনে ট্যাপ করে প্রজেক্ট ল্যাব ড্যাশবোর্ডে গিয়ে ধাপে ধাপে সম্পূর্ণ কোড ওয়াকথ্রু দেখে নিন।
