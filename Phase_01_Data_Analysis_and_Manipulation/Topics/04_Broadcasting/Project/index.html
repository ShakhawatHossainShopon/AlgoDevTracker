টপিক ০৪: ব্রডকাস্টিং ও মাল্টি-অ্যাসেট ফি ক্যালকুলেশন — প্র্যাকটিক্যাল ল্যাব

ভিন্ন শেপের ম্যাট্রিক্সে লুপ না চালিয়ে সম্পূর্ণ পোর্টফোলিও প্রাইস ম্যাট্রিক্সের ওপর ব্রোকারেজ ফি এবং বিড-আস্ক স্প্রেড একবারে অ্যাডজাস্ট করা।

প্রজেক্ট অবজেক্টিভ: নিচের কোড ব্লকগুলো ধাপে ধাপে পর্যবেক্ষণ করে অ্যালগরিদমটি কীভাবে কাজ করে তা আয়ত্ত করুন। প্রতিটি কোডের জন্য ওয়ান-ট্যাপ কপি বাটন রয়েছে।

০১ মাল্টিপল অ্যাসেট প্রাইসে স্প্রেড যোগ করা

step_01.py 
import numpy as np

# ৪টি অ্যাসেটের ৩ দিনের ক্লোজিং প্রাইস (3 x 4)
# Assets: [BTC, ETH, SOL, BNB]
prices = np.array([
    [67000.0, 3500.0, 180.0, 590.0],
    [67200.0, 3540.0, 185.0, 595.0],
    [67100.0, 3520.0, 182.0, 592.0]
])

# প্রতিটি অ্যাসেটের ফিক্সড স্প্রেড (1D array of 4 elements)
spreads = np.array([2.5, 0.5, 0.1, 0.2])

# ব্রডকাস্টিংয়ের মাধ্যমে আস্ক প্রাইস ম্যাট্রিক্স
ask_prices = prices + spreads
print("Original Prices (Day 1):", prices[0])
print("Ask Prices with Spread (Day 1):", ask_prices[0])

# 1. মাল্টিপল অ্যাসেট প্রাইসে স্প্রেড যোগ করা
import numpy as np

# ৪টি অ্যাসেটের ৩ দিনের ক্লোজিং প্রাইস (3 x 4)
# Assets: [BTC, ETH, SOL, BNB]
prices = np.array([
    [67000.0, 3500.0, 180.0, 590.0],
    [67200.0, 3540.0, 185.0, 595.0],
    [67100.0, 3520.0, 182.0, 592.0]
])

# প্রতিটি অ্যাসেটের ফিক্সড স্প্রেড (1D array of 4 elements)
spreads = np.array([2.5, 0.5, 0.1, 0.2])

# ব্রডকাস্টিংয়ের মাধ্যমে আস্ক প্রাইস ম্যাট্রিক্স
ask_prices = prices + spreads
print("Original Prices (Day 1):", prices[0])
print("Ask Prices with Spread (Day 1):", ask_prices[0])

# 2. ট্রেডিং ফি এবং স্লিপেজ ডিডাকশন
# ০.০৫% ট্রেডিং কমিশন ডিডাকশন
fee_multiplier = 0.9995  # স্কেলার মান
net_proceeds = prices * fee_multiplier

print("Net Proceeds after 0.05% Fee:
", np.round(net_proceeds, 2))

# 3. কলাম-ওয়াইজ নরমালাইজেশন
mean_prices = prices.mean(axis=0)  # Shape (4,)
normalized_prices = prices / mean_prices

print("Asset Means:", np.round(mean_prices, 1))
print("Normalized Prices (Base 1.0):
", np.round(normalized_prices, 4))
