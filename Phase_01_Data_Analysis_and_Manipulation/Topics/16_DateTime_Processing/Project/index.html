টপিক ১৬: ডেটটাইম প্রসেসিং ও মাল্টি-টাইমফ্রেম রিস্যাম্পলিং — প্র্যাকটিক্যাল ল্যাব

১ মিনিটের টিক ক্যান্ডেলগুলোকে ১৫ মিনিট ও ১ ঘণ্টার উচ্চতর টাইমফ্রেম বারে রিস্যাম্পল (Resample) করা।

প্রজেক্ট অবজেক্টিভ: নিচের কোড ব্লকগুলো ধাপে ধাপে পর্যবেক্ষণ করে অ্যালগরিদমটি কীভাবে কাজ করে তা আয়ত্ত করুন। প্রতিটি কোডের জন্য ওয়ান-ট্যাপ কপি বাটন রয়েছে।

০১ ১-মিনিট থেকে ৫-মিনিট ক্যান্ডেলে রিস্যাম্পল

step_01.py 
import pandas as pd

# ৫টি ১-মিনিটের ক্যান্ডেল
dates = pd.date_range("2026-08-01 09:30", periods=5, freq="min")
df_1m = pd.DataFrame({
    "Open": [100.0, 101.5, 102.0, 101.0, 102.5],
    "High": [101.8, 102.5, 103.0, 102.2, 103.5],
    "Low": [99.5, 101.0, 101.2, 100.8, 101.5],
    "Close": [101.5, 102.0, 101.0, 102.5, 103.0],
    "Volume": [50, 80, 40, 60, 110]
}, index=dates)

# ৫ মিনিটের একক বারে রিস্যাম্পলিং
df_5m = df_1m.resample("5min").agg({
    "Open": "first",
    "High": "max",
    "Low": "min",
    "Close": "last",
    "Volume": "sum"
})

print("Resampled 5-Minute Bar:\n", df_5m)
Terminal Output
Resampled 5-Minute Bar:
                       Open   High   Low  Close  Volume
2026-08-01 09:30:00  100.0  103.5  99.5  103.0     340
লাইন-বাই-লাইন বিশ্লেষণ: first, max, min, last এবং sum রুল দিয়ে নিখুঁত ৫ মিনিটের ওএইচএলসি ক্যান্ডেল সিন্থেসিস সম্পন্ন হয়েছে।
