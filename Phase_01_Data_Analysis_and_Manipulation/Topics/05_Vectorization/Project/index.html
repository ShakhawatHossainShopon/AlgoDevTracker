টপিক ০৫: ভেক্টরাইজেশন বনাম স্লো পাইথন লুপ — প্র্যাকটিক্যাল ল্যাব

১০ লক্ষ হিস্টোরিক্যাল ট্রিকে মুভিং অ্যাভারেজ এবং লগারিদমিক রিটার্ন গণনায় পাইথনের স্লো লুপ বর্জন করে ভেক্টরাইজড সি-অপারেশন প্রয়োগ।

প্রজেক্ট অবজেক্টিভ: নিচের কোড ব্লকগুলো ধাপে ধাপে পর্যবেক্ষণ করে অ্যালগরিদমটি কীভাবে কাজ করে তা আয়ত্ত করুন। প্রতিটি কোডের জন্য ওয়ান-ট্যাপ কপি বাটন রয়েছে।

০১ লগ রিটার্ন ক্যালকুলেশন: লুপ বনাম ভেক্টরাইজেশন

step_01.py 
import numpy as np

prices = np.array([100.0, 102.5, 101.8, 103.2, 105.0])

# ভেক্টরাইজড লগ রিটার্ন: r_t = ln(P_t / P_{t-1})
log_returns = np.log(prices[1:] / prices[:-1])

print("Prices:", prices)
print("Log Returns (Vectorized):", np.round(log_returns, 4))
Terminal Output
Prices: [100.  102.5 101.8 103.2 105. ]
Log Returns (Vectorized): [ 0.0247 -0.0069  0.0137  0.0173]
লাইন-বাই-লাইন বিশ্লেষণ: np.log এবং স্লাইসড ডিভিশন দিয়ে ১ লাইনে পুরো টাইম-সিরিজের লগ রিটার্ন ক্যালকুলেট করা হয়েছে।

০২ ভেক্টরাইজড বুলিয়ান কন্ডিশন (np.where)

step_02.py 
# সিগন্যাল তৈরি: রিটার্ন ধনাত্মক হলে 1 (Long), ঋণাত্মক হলে -1 (Short)
signals = np.where(log_returns > 0, 1, -1)

print("Generated Signals:", signals)
print("Long Signals Count:", np.sum(signals == 1))
Terminal Output
Generated Signals: [ 1 -1  1  1]
Long Signals Count: 3
লাইন-বাই-লাইন বিশ্লেষণ: np.where হলো ভেক্টরাইজড if-else যা কোনো ব্রাঞ্চিং লুপ ছাড়াই দ্রুত সিগন্যাল তৈরি করে।

০৩ কিউমুলেটিভ কম্পাউন্ডিং (np.cumprod)

step_03.py 
simple_returns = np.array([0.02, -0.01, 0.03, 0.015])
growth_factors = 1 + simple_returns
equity_curve = np.cumprod(growth_factors) * 10000  # $10k Initial Capital

print("Equity Curve Trajectory ($):", np.round(equity_curve, 2))
Terminal Output
Equity Curve Trajectory ($): [10200.   10098.   10400.94 10556.95]
লাইন-বাই-লাইন বিশ্লেষণ: np.cumprod ভেক্টরাইজড মেথডে মূলধন প্রতি ট্রেডে কীভাবে বৃদ্ধি পেয়েছে তার ইকুইটি কার্ভ বের করেছে।

★ সম্পূর্ণ পাইপলাইন স্ক্রিপ্ট (Full Integration)

complete_pipeline.py 
# 1. লগ রিটার্ন ক্যালকুলেশন: লুপ বনাম ভেক্টরাইজেশন
import numpy as np

prices = np.array([100.0, 102.5, 101.8, 103.2, 105.0])

# ভেক্টরাইজড লগ রিটার্ন: r_t = ln(P_t / P_{t-1})
log_returns = np.log(prices[1:] / prices[:-1])

print("Prices:", prices)
print("Log Returns (Vectorized):", np.round(log_returns, 4))

# 2. ভেক্টরাইজড বুলিয়ান কন্ডিশন (np.where)
# সিগন্যাল তৈরি: রিটার্ন ধনাত্মক হলে 1 (Long), ঋণাত্মক হলে -1 (Short)
signals = np.where(log_returns > 0, 1, -1)

print("Generated Signals:", signals)
print("Long Signals Count:", np.sum(signals == 1))

# 3. কিউমুলেটিভ কম্পাউন্ডিং (np.cumprod)
simple_returns = np.array([0.02, -0.01, 0.03, 0.015])
growth_factors = 1 + simple_returns
equity_curve = np.cumprod(growth_factors) * 10000  # $10k Initial Capital

print("Equity Curve Trajectory ($):", np.round(equity_curve, 2))
