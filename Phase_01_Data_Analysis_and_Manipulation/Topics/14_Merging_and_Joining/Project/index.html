টপিক ১৪: অ্যাসেট মার্জিং ও অ্যাসিনক্রোনাস টিক অ্যালাইনমেন্ট — প্র্যাকটিক্যাল ল্যাব

ম্যাক্রো-ইকোনমিক নিউজ ইভেন্ট ও ইন্টাররেস্ট রেটের সাথে হাই-ফ্রিকোয়েন্সি মার্কেট প্রাইস `merge_asof` দিয়ে নিখুঁতভাবে মার্জ করা।

প্রজেক্ট অবজেক্টিভ: নিচের কোড ব্লকগুলো ধাপে ধাপে পর্যবেক্ষণ করে অ্যালগরিদমটি কীভাবে কাজ করে তা আয়ত্ত করুন। প্রতিটি কোডের জন্য ওয়ান-ট্যাপ কপি বাটন রয়েছে।

০১ pd.merge_asof দিয়ে অ্যাসিঙ্ক্রোনাস টিক মার্জিং

step_01.py 
import pandas as pd

# ট্রেড এক্সিকিউশন টাইম
trades = pd.DataFrame({
    "time": pd.to_datetime(["2026-06-01 10:00:01", "2026-06-01 10:00:05", "2026-06-01 10:00:12"]),
    "ticker": ["BTC", "BTC", "BTC"],
    "trade_price": [67200, 67210, 67250]
})

# এক্সচেঞ্জ কোটেশন টাইম (আলাদা টাইমস্ট্যাম্প)
quotes = pd.DataFrame({
    "time": pd.to_datetime(["2026-06-01 10:00:00", "2026-06-01 10:00:04", "2026-06-01 10:00:10"]),
    "bid": [67198, 67208, 67245],
    "ask": [67202, 67212, 67252]
})

# ট্রেডের ঠিক পূর্ববর্তী সর্বশেষ কোটেশনের সাথে মার্জ
merged = pd.merge_asof(trades, quotes, on="time")
print("As-Of Merged Dataset:\n", merged)

1 2026-06-01 10:00:05    BTC        67210  67208  67212

লাইন-বাই-লাইন বিশ্লেষণ: merge_asof ব্যবহার করে প্রতি ট্রেড এক্সিকিউশনের ঠিক আগের বিড ও আস্ক প্রাইস নিখুঁতভাবে পাওয়া গেছে।

import pandas as pd

# ট্রেড এক্সিকিউশন টাইম

    "time": pd.to_datetime(["2026-06-01 10:00:01", "2026-06-01 10:00:05", "2026-06-01 10:00:12"]),
    "ticker": ["BTC", "BTC", "BTC"],
    "trade_price": [67200, 67210, 67250]
})

# এক্সচেঞ্জ কোটেশন টাইম (আলাদা টাইমস্ট্যাম্প)
quotes = pd.DataFrame({
    "time": pd.to_datetime(["2026-06-01 10:00:00", "2026-06-01 10:00:04", "2026-06-01 10:00:10"]),
    "bid": [67198, 67208, 67245],
    "ask": [67202, 67212, 67252]
})

# ট্রেডের ঠিক পূর্ববর্তী সর্বশেষ কোটেশনের সাথে মার্জ
