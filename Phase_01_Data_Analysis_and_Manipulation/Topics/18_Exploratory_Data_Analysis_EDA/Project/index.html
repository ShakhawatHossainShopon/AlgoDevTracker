টপিক ১৮: কমপ্লিট ফিন্যান্সিয়াল এক্সপ্লোরেটরি ডেটা অ্যানালাইসিস — প্র্যাকটিক্যাল ল্যাব

নতুন কোনো ক্রিপ্টো বা ফরেক্স অ্যাসেটের হিস্টোরিক্যাল ডেটায় ফ্যাট-টেলস (Kurtosis), স্কিউনেস এবং রিজিউম শিফট উন্মোচন করা।

প্রজেক্ট অবজেক্টিভ: নিচের কোড ব্লকগুলো ধাপে ধাপে পর্যবেক্ষণ করে অ্যালগরিদমটি কীভাবে কাজ করে তা আয়ত্ত করুন। প্রতিটি কোডের জন্য ওয়ান-ট্যাপ কপি বাটন রয়েছে।

০১ স্কিউনেস ও কার্টোসিস গণনা

step_01.py 
import pandas as pd
import numpy as np

# ফিন্যান্সিয়াল রিটার্ন ডেটাসেট
returns = pd.Series([0.002, 0.005, -0.045, 0.008, 0.001, -0.003, 0.035, -0.002])

skew = returns.skew()
kurt = returns.kurtosis()

print("Return Skewness:", round(skew, 3))
print("Return Kurtosis (Fat-tail):", round(kurt, 3))
Terminal Output
Return Skewness: -0.732
Return Kurtosis (Fat-tail): 2.418
লাইন-বাই-লাইন বিশ্লেষণ: নেগেটিভ স্কিউনেস নির্দেশ করে মার্কেট বড় পতনের ঝুঁকি বহন করে এবং হাই কার্টোসিস ফ্যাট টেইলস নির্দেশ করে।

০২ ভ্যালু অ্যাট রিস্ক (VaR 95%) ও CVaR

step_02.py 
# হিস্টোরিক্যাল ৯৫% VaR (৫ম পারসেন্টাইল)
var_95 = np.percentile(returns, 5)
cvar_95 = returns[returns <= var_95].mean()

print("Historical 95% Daily VaR:", round(var_95 * 100, 2), "%")
print("Conditional VaR (Expected Shortfall):", round(cvar_95 * 100, 2), "%")
Terminal Output
Historical 95% Daily VaR: -3.05 %
Conditional VaR (Expected Shortfall): -4.5 %
লাইন-বাই-লাইন বিশ্লেষণ: ৯৫% আস্থায় একদিনে সর্বোচ্চ ক্ষতি হতে পারে ৩.০৫% এবং চরম পতনের ক্ষেত্রে গড় ক্ষতি (CVaR) ৪.৫%।

# 1. স্কিউনেস ও কার্টোসিস গণনা
import pandas as pd
import numpy as np

# ফিন্যান্সিয়াল রিটার্ন ডেটাসেট
returns = pd.Series([0.002, 0.005, -0.045, 0.008, 0.001, -0.003, 0.035, -0.002])

skew = returns.skew()
kurt = returns.kurtosis()

print("Return Skewness:", round(skew, 3))
print("Return Kurtosis (Fat-tail):", round(kurt, 3))

# 2. ভ্যালু অ্যাট রিস্ক (VaR 95%) ও CVaR
# হিস্টোরিক্যাল ৯৫% VaR (৫ম পারসেন্টাইল)
var_95 = np.percentile(returns, 5)
cvar_95 = returns[returns <= var_95].mean()

print("Historical 95% Daily VaR:", round(var_95 * 100, 2), "%")
print("Conditional VaR (Expected Shortfall):", round(cvar_95 * 100, 2), "%")

# 3. ভলিউম-প্রাইস মোমেন্টাম চেক
