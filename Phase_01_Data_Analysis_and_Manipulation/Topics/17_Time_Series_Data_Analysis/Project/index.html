টপিক ১৭: টাইম-সিরিজ অ্যানালাইসিস ও রোলিং স্ট্যাটিস্টিকস — প্র্যাকটিক্যাল ল্যাব

রোলিং সিম্পল মুভিং অ্যাভারেজ (SMA), এক্সপোনেনশিয়াল মুভিং অ্যাভারেজ (EMA) এবং ম্যাক্সিমাম ড্রডাউন ট্র্যাক করা।

প্রজেক্ট অবজেক্টিভ: নিচের কোড ব্লকগুলো ধাপে ধাপে পর্যবেক্ষণ করে অ্যালগরিদমটি কীভাবে কাজ করে তা আয়ত্ত করুন। প্রতিটি কোডের জন্য ওয়ান-ট্যাপ কপি বাটন রয়েছে।

০১ SMA এবং EMA ক্যালকুলেশন

step_01.py 
import pandas as pd

prices = pd.Series([100, 102, 104, 103, 105, 107, 106, 108, 110, 112])

# ৩-পিরিয়ড SMA
sma3 = prices.rolling(window=3).mean()

# ৩-পিরিয়ড EMA
ema3 = prices.ewm(span=3, adjust=False).mean()

res = pd.DataFrame({"Price": prices, "SMA_3": sma3, "EMA_3": ema3})
print(res.tail(4).round(2))

লাইন-বাই-লাইন বিশ্লেষণ: rolling() এবং ewm() দিয়ে ট্রেন্ড ট্র্যাকিং মুভিং অ্যাভারেজ হিসাব করা হয়েছে।

০৩ পিক-টু-ট্রাফ ম্যাক্সিমাম ড্রডাউন (MDD)

equity = pd.Series([10000, 10500, 10300, 9800, 10200, 10600])

running_max = equity.cummax()
drawdown = (equity - running_max) / running_max
max_drawdown = drawdown.min()

# 1. SMA এবং EMA ক্যালকুলেশন
import pandas as pd

prices = pd.Series([100, 102, 104, 103, 105, 107, 106, 108, 110, 112])

# ৩-পিরিয়ড SMA
sma3 = prices.rolling(window=3).mean()

# ৩-পিরিয়ড EMA
ema3 = prices.ewm(span=3, adjust=False).mean()

res = pd.DataFrame({"Price": prices, "SMA_3": sma3, "EMA_3": ema3})
print(res.tail(4).round(2))

# 2. রোলিং ভোলাটিলিটি ক্যালকুলেশন
returns = prices.pct_change()
rolling_vol = returns.rolling(window=3).std() * (252 ** 0.5)

print("Rolling Annualized Volatility:\n", rolling_vol.tail(3).round(4))

# 3. পিক-টু-ট্রাফ ম্যাক্সিমাম ড্রডাউন (MDD)
equity = pd.Series([10000, 10500, 10300, 9800, 10200, 10600])

running_max = equity.cummax()
drawdown = (equity - running_max) / running_max
max_drawdown = drawdown.min()

print("Peak Capital History:\n", running_max)
print("\nMax Drawdown (Worst Loss from Peak):", round(max_drawdown * 100, 2), "%")
