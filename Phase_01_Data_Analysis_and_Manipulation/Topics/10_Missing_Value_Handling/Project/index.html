টপিক ১০: মিসিং ভ্যালু হ্যান্ডলিং ও লুক-অ্যাহেড বায়াস প্রতিরোধ — প্র্যাকটিক্যাল ল্যাব

মার্কেটের ছুটির দিন বা কম লিকুইডিটির সময়ে অনুপস্থিত ক্যান্ডেলগুলোকে ফরওয়ার্ড ফিল (ffill) দিয়ে লুক-অ্যাহেড বায়াস মুক্ত রাখা।

প্রজেক্ট অবজেক্টিভ: নিচের কোড ব্লকগুলো ধাপে ধাপে পর্যবেক্ষণ করে অ্যালগরিদমটি কীভাবে কাজ করে তা আয়ত্ত করুন। প্রতিটি কোডের জন্য ওয়ান-ট্যাপ কপি বাটন রয়েছে।

০১ ফরওয়ার্ড ফিল (Last Known Price)

step_01.py 
import pandas as pd
import numpy as np

timestamps = pd.date_range("2026-04-01 09:30", periods=5, freq="min")
prices = pd.Series([150.25, np.nan, np.nan, 151.10, 150.90], index=timestamps)

# ফরওয়ার্ড ফিল: আগের প্রাইস বজায় রাখা
filled_ffill = prices.ffill()

print("Original Series:\n", prices)
print("\nForward Filled Series:\n", filled_ffill)

complete_pipeline.py 
# 1. ফরওয়ার্ড ফিল (Last Known Price)
import pandas as pd
import numpy as np

timestamps = pd.date_range("2026-04-01 09:30", periods=5, freq="min")
prices = pd.Series([150.25, np.nan, np.nan, 151.10, 150.90], index=timestamps)

# ফরওয়ার্ড ফিল: আগের প্রাইস বজায় রাখা
filled_ffill = prices.ffill()

print("Original Series:\n", prices)
print("\nForward Filled Series:\n", filled_ffill)

# 2. ভলিউমের ক্ষেত্রে জিরো ফিলিং (fillna 0)
volumes = pd.Series([500, np.nan, np.nan, 1200, 800], index=timestamps)
# ট্রেড না হওয়া মিনিটে ভলিউম হবে ০
filled_volumes = volumes.fillna(0)

print("Volume with 0 for Inactive Minutes:\n", filled_volumes)

# 3. মিসিং ভ্যালুর পরিমাণ ও শতাংশ গণনা
df_sample = pd.DataFrame({"P": prices, "V": volumes})
print("Missing Value Counts:\n", df_sample.isna().sum())
print("\nMissing Percentage (%):\n", (df_sample.isna().mean() * 100).round(1))
