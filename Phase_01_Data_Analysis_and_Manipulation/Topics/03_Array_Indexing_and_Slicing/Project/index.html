টপিক ০৩: অ্যারে ইনডেক্সিং, স্লাইসিং ও বুলিয়ান ফিল্টারিং — প্র্যাকটিক্যাল ল্যাব

ঐতিহাসিক ৫ মিনিটের ক্যান্ডেলস্টিক ডেটা থেকে উচ্চ ভোলাটিলিটি বার ও অস্বাভাবিক ভলিউম স্পাইক তাৎক্ষণিকভাবে ফিল্টার করা।

প্রজেক্ট অবজেক্টিভ: নিচের কোড ব্লকগুলো ধাপে ধাপে পর্যবেক্ষণ করে অ্যালগরিদমটি কীভাবে কাজ করে তা আয়ত্ত করুন। প্রতিটি কোডের জন্য ওয়ান-ট্যাপ কপি বাটন রয়েছে।

০১ 2D OHLCV ক্যান্ডেল স্লাইসিং

step_01.py 
import numpy as np

# ক্যান্ডেল ডেটা: [Open, High, Low, Close, Volume]
candles = np.array([
    [67000, 67200, 66950, 67150, 150.0],
    [67150, 67400, 67100, 67350, 280.0],
    [67350, 67500, 67250, 67300, 95.0],
    [67300, 67600, 67280, 67580, 410.0]
])

close_prices = candles[:, 3]
volumes = candles[:, 4]

print("All Close Prices:", close_prices)
print("Latest 2 Candle Volumes:", volumes[-2:])
Terminal Output
All Close Prices: [67150. 67350. 67300. 67580.]
Latest 2 Candle Volumes: [ 95. 410.]
লাইন-বাই-লাইন বিশ্লেষণ: [:, 3] দিয়ে সব সারির ৪ নম্বর কলাম (Close) এবং [-2:] দিয়ে শেষ দুই ক্যান্ডেলের ভলিউম স্লাইস করা হয়েছে।

import numpy as np

# ক্যান্ডেল ডেটা: [Open, High, Low, Close, Volume]

    [67000, 67200, 66950, 67150, 150.0],
    [67150, 67400, 67100, 67350, 280.0],
    [67350, 67500, 67250, 67300, 95.0],
    [67300, 67600, 67280, 67580, 410.0]
])

close_prices = candles[:, 3]
volumes = candles[:, 4]

print("All Close Prices:", close_prices)
print("Latest 2 Candle Volumes:", volumes[-2:])
