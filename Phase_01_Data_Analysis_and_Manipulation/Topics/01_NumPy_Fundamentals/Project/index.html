টপিক ০১: NumPy ফান্ডামেন্টালস ও কোয়ান্টাম স্পিড মেমোরি — প্র্যাকটিক্যাল ল্যাব

হাই-ফ্রিকোয়েন্সি ট্রেডিং ডেটাসেটে পাইথনের সাধারণ লিস্টের মেমোরি ওভারহেড দূর করে সি-লেভেলের দ্রুততম মেমোরি বাফার এবং ndarray আর্কিটেকচার তৈরি করা।

প্রজেক্ট অবজেক্টিভ: নিচের কোড ব্লকগুলো ধাপে ধাপে পর্যবেক্ষণ করে অ্যালগরিদমটি কীভাবে কাজ করে তা আয়ত্ত করুন। প্রতিটি কোডের জন্য ওয়ান-ট্যাপ কপি বাটন রয়েছে।

০১ NumPy ndarray তৈরি ও মেমোরি সাইজ পরীক্ষা

step_01.py 
import numpy as np
import sys

# সাধারণ পাইথন লিস্ট বনাম NumPy অ্যারে
py_list = [100.5, 101.2, 99.8, 102.4, 103.1]
np_arr = np.array(py_list, dtype=np.float64)

print("Python List Size in Bytes:", sys.getsizeof(py_list))
print("NumPy Array Size in Bytes:", np_arr.nbytes)
print("Array Shape:", np_arr.shape)
print("Data Type:", np_arr.dtype)
Terminal Output
Python List Size in Bytes: 104
NumPy Array Size in Bytes: 40
Array Shape: (5,)
Data Type: float64
লাইন-বাই-লাইন বিশ্লেষণ: NumPy অ্যারে প্রতিটি উপাদানের জন্য ফিক্সড ৮ বাইট (float64) মেমোরি নেয়, যেখানে পাইথন লিস্ট প্রতিটি ফ্লোটের রেফারেন্স ও মেটাডেটার জন্য বিশাল মেমোরি অপচয় করে।

step_02.py 
# ১ মিলিয়ন প্রাইস টিকের দ্রুত প্রসেসিং
prices = np.array([67200.0, 67250.5, 67180.0, 67320.0, 67400.5])

# ভেক্টরাইজড রিটার্ন ক্যালকুলেশন
pct_returns = (prices[1:] - prices[:-1]) / prices[:-1] * 100

print("Price Changes (%):", np.round(pct_returns, 3))
print("Average Return:", round(np.mean(pct_returns), 4), "%")

Average Return: 0.0747 %
লাইন-বাই-লাইন বিশ্লেষণ: কোনো for-loop ছাড়াই অ্যারের স্লাইসিং এবং ভেক্টরাইজেশনের মাধ্যমে চোখের পলকে প্রতি ট্রেডের পার্সেন্টেজ রিটার্ন বের করা হয়েছে।

০৩ NumPy গাণিতিক ফাংশন ও ভোল্টেবিলিটি

step_03.py 
# বার্ষিক ভোলাটিলিটি ক্যালকুলেশন
daily_returns = np.array([0.012, -0.008, 0.015, -0.004, 0.009, -0.011])

volatility = np.std(daily_returns)
annualized_vol = volatility * np.sqrt(252)

print("Daily Volatility (Std):", round(volatility, 5))
print("Annualized Volatility:", round(annualized_vol * 100, 2), "%")
Terminal Output
Daily Volatility (Std): 0.01041
Annualized Volatility: 16.53 %
লাইন-বাই-লাইন বিশ্লেষণ: np.std দিয়ে স্ট্যান্ডার্ড ডেভিয়েশন এবং np.sqrt(252) দিয়ে অ্যানুয়ালাইজড ভোলাটিলিটি নিখুঁতভাবে বের করা হয়েছে।
