ট্রেডিং প্রেক্ষাপট: ক্যান্ডেলস্টিক প্রাইস সিরিজ থেকে ভেক্টরাইজড স্লাইসিংয়ের মাধ্যমে সিম্পল ও লগ রিটার্ন হিসাব এবং এডিটিভিটি পরীক্ষা।

০১ ধাপ ১: স্লাইসিং দিয়ে সিম্পল রিটার্ন হিসাব

step_01.py 
import numpy as np

prices = np.array([100.0, 102.5, 101.0, 104.0, 106.5])

# prices[1:] হলো বর্তমান ক্যান্ডেল, prices[:-1] হলো পূর্ববর্তী ক্যান্ডেল
simple_returns = (prices[1:] - prices[:-1]) / prices[:-1]

print("Closing Prices:", prices)
print("Simple Returns (%):", np.round(simple_returns * 100, 2))
Terminal Output
Closing Prices: [100.  102.5 101.  104.  106.5]
Simple Returns (%): [ 2.5  -1.46  2.97  2.4 ]
লাইন-বাই-লাইন বিশ্লেষণ: কোনো for লুপ ছাড়াই NumPy অ্যারে স্লাইসিং দিয়ে এক লাইনে ৪টি ক্যান্ডেলের রিটার্ন বের করা হয়েছে।

০২ ধাপ ২: লগ রিটার্ন ও যোগ করার সুবিধা (Additivity)

step_02.py 
log_returns = np.diff(np.log(prices))

sum_log = np.sum(log_returns)
total_period_log = np.log(prices[-1] / prices[0])

print("Log Returns (%):", np.round(log_returns * 100, 2))
print("Sum of Log Returns:", round(sum_log, 4))
print("Total Period Log Return:", round(total_period_log, 4))
print("Additivity Identity Holds?:", np.isclose(sum_log, total_period_log))
Terminal Output
Log Returns (%): [ 2.47 -1.47  2.93  2.38]
Sum of Log Returns: 0.063
Total Period Log Return: 0.063
Additivity Identity Holds?: True
লাইন-বাই-লাইন বিশ্লেষণ: np.diff এবং np.log ব্যবহার করে লগ রিটার্ন বের করা হয়েছে এবং প্রমাণ করা হয়েছে যে প্রতিটি বারের লগ রিটার্ন যোগ করলেই পুরো পিরিয়ডের মোট রিটার্ন পাওয়া যায়।

০৩ ধাপ ৩: ফিচার স্কেলিং (Z-Score Standardization)

step_03.py 
# মোমেন্টাম ও ভলিউমের মতো ভিন্ন স্কেলের ফিচারকে গড়=০ ও ভ্যারিয়েন্স=১ এ রূপান্তর
features = np.array([
    [2.5, 1800],
    [-1.4, 900],
    [3.0, 2200],
    [2.4, 1500]
])

mean = np.mean(features, axis=0)
std = np.std(features, axis=0)
scaled_features = (features - mean) / std

print("Scaled Feature Matrix (Mean=0, Std=1):\n", np.round(scaled_features, 2))

# Basic Algebra & Vectorization: Return Transformations

# 1. ধাপ ১: স্লাইসিং দিয়ে সিম্পল রিটার্ন হিসাব
import numpy as np

prices = np.array([100.0, 102.5, 101.0, 104.0, 106.5])

# prices[1:] হলো বর্তমান ক্যান্ডেল, prices[:-1] হলো পূর্ববর্তী ক্যান্ডেল
simple_returns = (prices[1:] - prices[:-1]) / prices[:-1]

print("Closing Prices:", prices)
print("Simple Returns (%):", np.round(simple_returns * 100, 2))

# 2. ধাপ ২: লগ রিটার্ন ও যোগ করার সুবিধা (Additivity)
log_returns = np.diff(np.log(prices))

sum_log = np.sum(log_returns)
total_period_log = np.log(prices[-1] / prices[0])

print("Log Returns (%):", np.round(log_returns * 100, 2))
print("Sum of Log Returns:", round(sum_log, 4))
print("Total Period Log Return:", round(total_period_log, 4))
print("Additivity Identity Holds?:", np.isclose(sum_log, total_period_log))
