Phase 02: Mathematics for Data Science Project ০২: Visual Walkthrough

সমীকরণ ও অসমতা: ব্রেক-ইভেন এক্সিট ও পজিশন সাইজিং

ট্রেডিং প্রেক্ষাপট: ট্রেডিং ফি বিবেচনায় নিয়ে ব্রেক-ইভেন প্রাইস সমীকরণ এবং রিস্ক-রিওয়ার্ড অসমতা ফিল্টার প্রয়োগ।

০১ ধাপ ১: ব্রেক-ইভেন প্রাইস সমীকরণ

step_01.py 
entry_price = 100.0
fee_rate = 0.001  # 0.1% fee per side

# কস্ট রিকভার করতে এক্সিট প্রাইস সমীকরণ
break_even_price = entry_price * (1 + fee_rate) / (1 - fee_rate)

print("Entry Price: $", entry_price)
print("Trading Fee Rate:", fee_rate * 100, "%")
print("Break-Even Exit Price: $", round(break_even_price, 4))
Terminal Output
Entry Price: $ 100.0
Trading Fee Rate: 0.1 %
Break-Even Exit Price: $ 100.2002
লাইন-বাই-লাইন বিশ্লেষণ: কেনার সময় এবং বেচার সময় উভয় পাশের ফি বিবেচনায় নিয়ে এক্সাক্ট ব্রেক-ইভেন প্রাইস বের করা হয়েছে।

০২ ধাপ ২: পজিশন সাইজিং সমীকরণ (১% রিস্ক নিয়ম)

step_02.py 
capital = 10000.0
risk_pct = 0.01
stop_loss = 95.0

max_risk_dollars = capital * risk_pct
loss_per_share = entry_price - stop_loss
shares_to_buy = max_risk_dollars / loss_per_share

print("Account Capital: $", capital)
print("Max Risk Allowed (1%): $", max_risk_dollars)
print("Loss Per Share: $", loss_per_share)
print("Exact Shares to Buy:", shares_to_buy)
Terminal Output
Account Capital: $ 10000.0
Max Risk Allowed (1%): $ 100.0
Loss Per Share: $ 5.0
Exact Shares to Buy: 20.0
লাইন-বাই-লাইন বিশ্লেষণ: বীজগণিতের সমীকরণ দিয়ে ঠিক ২০টি শেয়ার কেনার সিদ্ধান্ত হয়েছে যাতে স্টপলস হিট করলেও মাত্র ১০০ ডলারের বেশি ক্ষতি না হয়।

০৩ ধাপ ৩: রিস্ক-রিওয়ার্ড অসমতা ফিল্টার (Inequality)

step_03.py 
take_profit = 112.0

profit_per_share = take_profit - entry_price
rr_ratio = profit_per_share / loss_per_share
is_trade_approved = rr_ratio >= 1.5

print("Potential Profit Per Share: $", profit_per_share)
print("Risk-Reward Ratio:", round(rr_ratio, 2))
print("Is Trade Approved (RR >= 1.5)?:", is_trade_approved)
Terminal Output
Potential Profit Per Share: $ 12.0
Risk-Reward Ratio: 2.4
Is Trade Approved (RR >= 1.5)?: True
লাইন-বাই-লাইন বিশ্লেষণ: অসমতা (>=) ব্যবহার করে নিশ্চিত করা হয়েছে যে ট্রেডটি প্রত্যাশিত মুনাফার মানদণ্ড পূরণ করে কি না।

# Equations & Inequalities for Risk Management

# 1. ধাপ ১: ব্রেক-ইভেন প্রাইস সমীকরণ
entry_price = 100.0
fee_rate = 0.001  # 0.1% fee per side

# কস্ট রিকভার করতে এক্সিট প্রাইস সমীকরণ

print("Entry Price: $", entry_price)
print("Trading Fee Rate:", fee_rate * 100, "%")
print("Break-Even Exit Price: $", round(break_even_price, 4))

# 2. ধাপ ২: পজিশন সাইজিং সমীকরণ (১% রিস্ক নিয়ম)
capital = 10000.0
risk_pct = 0.01

print("Account Capital: $", capital)

# 3. ধাপ ৩: রিস্ক-রিওয়ার্ড অসমতা ফিল্টার (Inequality)
