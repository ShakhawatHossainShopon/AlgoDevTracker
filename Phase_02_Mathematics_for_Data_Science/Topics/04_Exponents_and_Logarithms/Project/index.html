সূচক ও লগারিদম: চক্রবৃদ্ধি সুদ ও অবিচ্ছিন্ন কম্পাউন্ডিং

ট্রেডিং প্রেক্ষাপট: বার্ষিক চক্রবৃদ্ধি রিটার্ন (CAGR) এবং অবিচ্ছিন্ন চক্রবৃদ্ধি বৃদ্ধি হিসাব করা।

০১ ধাপ ১: এক্সপোনেনশিয়াল কম্পাউন্ডিং (Continuous Compounding)

step_01.py 
import math

initial_capital = 10000.0
annual_rate = 0.15  # 15% annual return
years = 3

# অবিচ্ছিন্ন চক্রবৃদ্ধি ফর্মুলা: A = P * e^(rt)
future_val = initial_capital * math.exp(annual_rate * years)

print("Starting Capital: $", initial_capital)
print("Continuous Compounded Value after 3 years: $", round(future_val, 2))
Terminal Output
Starting Capital: $ 10000.0
Continuous Compounded Value after 3 years: $ 15683.12
লাইন-বাই-লাইন বিশ্লেষণ: math.exp() ব্যবহার করে ১৫% হারে ৩ বছরের অবিচ্ছিন্ন বৃদ্ধির চূড়ান্ত মূলধন বের করা হয়েছে।

০৪ সম্পূর্ণ কার্যকর কোড (Full Script)

নিচের কোডটি এক ট্যাপে কপি করে অন্য যেকোনো জায়গায় টেস্ট বা স্টাডি করতে পারেন:

complete_solution.py 
# Exponents & Logarithms in Continuous Compounding

# 1. ধাপ ১: এক্সপোনেনশিয়াল কম্পাউন্ডিং (Continuous Compounding)
import math

initial_capital = 10000.0
annual_rate = 0.15  # 15% annual return
years = 3

# অবিচ্ছিন্ন চক্রবৃদ্ধি ফর্মুলা: A = P * e^(rt)
future_val = initial_capital * math.exp(annual_rate * years)

print("Starting Capital: $", initial_capital)
print("Continuous Compounded Value after 3 years: $", round(future_val, 2))

# 2. ধাপ ২: প্রাকৃতিক লগারিদম দিয়ে ডাবলিং পিরিয়ড নির্ণয়
# মূলধন দ্বিগুণ হতে কত বছর লাগবে? ln(2) / r
doubling_years = math.log(2) / annual_rate

print(f"At {annual_rate * 100}% annual rate, capital doubles in: {doubling_years:.2f} years")

# 3. ধাপ ৩: লগ প্রাইস স্কেল নরমালাইজেশন
prices = [100.0, 200.0, 400.0, 800.0]
log_prices = [round(math.log(p), 4) for p in prices]

print("Raw Geometric Prices:", prices)
print("Log-Transformed Prices (Linear Steps):", log_prices)
print("Step Differences in Log Space:", [round(log_prices[i] - log_prices[i-1], 4) for i in range(1, len(log_prices))])
