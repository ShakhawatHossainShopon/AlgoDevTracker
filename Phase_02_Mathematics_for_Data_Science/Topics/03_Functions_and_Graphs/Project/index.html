ফাংশন ও গ্রাফ: ট্রেডিং পেঅফ ও ভিজ্যুয়ালাইজেশন

ট্রেডিং প্রেক্ষাপট: লং পজিশনের পেঅফ ফাংশন তৈরি এবং একাধিক প্রাইস পয়েন্টে গ্রাফ কোঅর্ডিনেট বিশ্লেষণ।

০১ ধাপ ১: ট্রেডিং পেঅফ ফাংশন তৈরি

step_01.py 
entry_price = 100.0
shares = 10

def calculate_pnl(current_price):
    return (current_price - entry_price) * shares

print("PnL at $110:", calculate_pnl(110.0))
print("PnL at $90 :", calculate_pnl(90.0))

PnL at $110: 100.0
PnL at $90 : -100.0

০৪ সম্পূর্ণ কার্যকর কোড (Full Script)

নিচের কোডটি এক ট্যাপে কপি করে অন্য যেকোনো জায়গায় টেস্ট বা স্টাডি করতে পারেন:

complete_solution.py 
# Functions & Payoff Graphs in Trading

# 1. ধাপ ১: ট্রেডিং পেঅফ ফাংশন তৈরি
entry_price = 100.0
shares = 10

def calculate_pnl(current_price):
    return (current_price - entry_price) * shares

print("PnL at $110:", calculate_pnl(110.0))
print("PnL at $90 :", calculate_pnl(90.0))

# 2. ধাপ ২: গ্রাফের জন্য কোঅর্ডিনেট টেবিল তৈরি
prices = [90.0, 95.0, 100.0, 105.0, 110.0]

print("Price (x)  -->  PnL (y)")
print("-" * 25)
for p in prices:
    pnl = calculate_pnl(p)
    print(f"x = ${p:<6.1f} --> y = ${pnl:>+6.1f}")

# 3. ধাপ ৩: স্লোপ ও পেঅফ সেনসিটিভিটি
# ঢাল (Slope) = Delta Y / Delta X = Shares
delta_y = calculate_pnl(110.0) - calculate_pnl(100.0)
delta_x = 110.0 - 100.0
slope = delta_y / delta_x

print("Payoff Graph Slope (Delta PnL / Delta Price):", slope)
print("Interpretation: Every $1 move generates $", slope, "profit/loss.")
