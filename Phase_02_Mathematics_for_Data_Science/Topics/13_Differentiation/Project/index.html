ডিফারেনসিয়েশন: তাৎক্ষণিক গতিবেগ ও প্রাইস মোমেন্টাম

ট্রেডিং প্রেক্ষাপট: প্রাইস কার্ভের তাৎক্ষণিক ঢাল (Derivative) বের করে মোমেন্টাম এক্সেলারেশন মাপা।

০১ ধাপ ১: ডিসক্রিট নিউমেরিক্যাল ডেরিভেটিভ (dy/dt)

step_01.py 
import numpy as np

prices = np.array([100.0, 101.5, 104.0, 108.0, 113.0])
# ১ম ডেরিভেটিভ: প্রাইজ ভেলোসিটি (পয়েন্ট পার বার)
velocity = np.diff(prices)

print("Price Series:", prices)
print("1st Derivative - Price Velocity (Speed per bar):", velocity)
Terminal Output
Price Series: [100.  101.5 104.  108.  113. ]
1st Derivative - Price Velocity (Speed per bar): [1.5 2.5 4.  5. ]
লাইন-বাই-লাইন বিশ্লেষণ: প্রাইসের বৃদ্ধি প্রতি বারে ১.৫ থেকে বেড়ে ৫.০ হচ্ছে, অর্থাৎ ট্রেন্ড আরও শক্তিশালী হচ্ছে।

০৩ সম্পূর্ণ কার্যকর কোড (Full Script)

নিচের কোডটি এক ট্যাপে কপি করে অন্য যেকোনো জায়গায় টেস্ট বা স্টাডি করতে পারেন:

complete_solution.py 
# Differentiation & Price Velocity in Trading

# 1. ধাপ ১: ডিসক্রিট নিউমেরিক্যাল ডেরিভেটিভ (dy/dt)
import numpy as np

prices = np.array([100.0, 101.5, 104.0, 108.0, 113.0])
# ১ম ডেরিভেটিভ: প্রাইজ ভেলোসিটি (পয়েন্ট পার বার)
velocity = np.diff(prices)

print("Price Series:", prices)
print("1st Derivative - Price Velocity (Speed per bar):", velocity)

# 2. ধাপ ২: ২য় ডেরিভেটিভ (Momentum Acceleration)
# ২য় ডেরিভেটিভ: ত্বরণ
acceleration = np.diff(velocity)
print("2nd Derivative - Acceleration:", acceleration)
print("Status:", "BULLISH ACCELERATING 🚀" if np.all(acceleration > 0) else "SLOWING DOWN")
